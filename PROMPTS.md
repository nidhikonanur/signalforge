> You are helping me build an impressive software engineering portfolio project tailored for Tesla’s Software Engineer, Integration Tools internship.
>

> signalforge
>

> Build a developer tool called SignalForge that reads YAML interface schemas describing messages between software components and generates strongly typed code, documentation, validation reports, and a communication graph.
>
> This project should demonstrate:
> - Python developer tooling
> - Rust code generation
> - internal tools mindset
> - schema validation
> - code generation
> - clean API design
> - maintainable architecture

> - debugging and reliability

> This is an original portfolio project. Do not use Tesla branding, logos, proprietary terms, vehicle-specific confidential concepts, or real embedded system definitions. Use generic component names such as BatteryController, MotorController, ThermalManager, SafetyMonitor, and TelemetryService.
>
> Target role requirements to optimize for:
> - Python experience
> - Rust experience
> - excitement for internal tools
> - code generation
> - developer productivity tooling
> - component interface modeling
> - scalable and maintainable system design
> - clean, well-documented code
> - debugging for performance and reliability
> - autonomy and resourcefulness
> - data structures and algorithms
> - internal analysis and visualization tools
>
> Core concept:
> SignalForge is a CLI tool that converts component communication schemas into generated code and documentation.
